# 🚀 RojgarSathi – Job Portal for Unorganized Workers

## 📌 Overview

RojgarSathi is a full-stack MERN-based web application designed to connect unorganized workers with employers through a simple, multilingual, and real-time communication platform.

The platform focuses on solving real-world challenges such as language barriers, lack of digital access, and delayed hiring processes by enabling instant communication and easy job matching.

---

## 🎯 Problem Statement

* Limited access to digital job platforms for unorganized workers
* Language barriers in existing job portals
* Dependency on middlemen
* Delay in hiring due to lack of real-time communication

---

## 💡 Solution

RojgarSathi provides a user-friendly platform where workers and employers can directly connect, communicate in real-time, and complete the hiring process efficiently without intermediaries.

---

## ✨ Features

* 🔐 User Authentication (JWT-based)
* 👥 Role-Based Access (Worker, Employer, Admin)
* 💬 Real-Time Chat (Socket.IO)
* 🌐 Multilingual Support (i18n)
* 📍 Location-Based Job Matching
* 📊 Admin Dashboard & Analytics
* 📄 Job Posting & Application System

---

## 🛠️ Tech Stack

**Frontend:** React.js
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Real-Time:** Socket.IO
**Authentication:** JWT
**Other Tools:** Multer, i18n

---

## ☁️ Deployment

* 🌍 Frontend: Vercel
* ⚙️ Backend: Render

---

## 🏗️ Architecture

* MERN Stack (MongoDB, Express, React, Node.js)
* REST APIs + WebSockets Integration
* 3-Tier Architecture (Frontend, Backend, Database)

---

## 🔄 Workflow

1. User registers as Worker or Employer
2. Worker creates profile & searches jobs
3. Employer posts job listings
4. Worker applies for job
5. Real-time chat is enabled after shortlist
6. Hiring process completed

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/your-username/rojgarsathi.git
cd rojgarsathi
```

### 2. Install Dependencies

```bash
npm install
cd client
npm install
```

### 3. Setup Environment Variables

Create `.env` file in root:

```
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
```

### 4. Run Project

```bash
# backend
npm run server

# frontend
cd client
npm start
```
